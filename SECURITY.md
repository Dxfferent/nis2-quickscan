# Security

De tool is een statische site zonder backend of account: antwoorden blijven
in de browser en verlaten het apparaat alleen als de bezoeker zelf het
rapport per e-mail aanvraagt (HubSpot-formulier van de deployende partij).

Kwetsbaarheid gevonden (bijv. XSS via de config, een lek in de lead-gate of
een dependency-issue)? Mail **hallo@dxfferent.nl** — geen publieke issue voor
onopgeloste kwetsbaarheden. We reageren binnen 5 werkdagen.
